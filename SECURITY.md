# Security reporting

Do not include real SSNs, passwords, recordings of personal typing, or actual form contents in issues or reports. Use the dummy `000-00-0000` and synthetic webpages.

For a non-sensitive bug, open a GitHub issue. For a vulnerability, use GitHub's private vulnerability reporting option in this repository's Security tab if the owner has enabled it. Otherwise contact the maintainer through their [GitHub profile](https://github.com/tsengf) to arrange a private channel before sharing exploit details.

This extension is an early accidental-disclosure aid. The [limitations](docs/LIMITATIONS.md) explain its threat model; it does not provide a security boundary against a determined malicious webpage or other software on the computer.
