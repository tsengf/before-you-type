# Chrome Web Store listing copy

## Name

BeforeYouType — SSN Warnings

## Short description

Pause before sharing your Social Security number. Local warnings for SSN fields, typing, and pasting. No accounts or tracking.

## Detailed description

BeforeYouType gives you a moment to think before sharing your Social Security number online.

It warns when you focus a recognizable Social Security number field and checks typing or pasting in other editable webpage fields for SSN-like numbers. Choose Cancel if you are unsure, or deliberately allow that field when you have verified the request.

• Early warnings on recognizable SSN fields, including labeled split fields.
• Checks for common SSN formats in supported editable fields.
• A clear Cancel or Allow choice, with field approvals reset on reload.
• Local processing with no SSN enrollment, accounts, analytics or saved typing history.
• A toolbar status check for the current webpage.

Protection has limits. Websites may read digits as you type, before a warning. Some autofill, input methods, custom editors and malicious page behavior can bypass interception. Nine-digit identifiers and some phone numbers can trigger false alarms. BeforeYouType is an accidental-disclosure aid and cannot guarantee that your information will not be disclosed. It does not validate that a website is safe.

Works on supported webpages in Chrome. Internal Chrome pages, the Web Store, other browsers and desktop applications are not covered. Incognito and local files require separate opt-in. Website access is required to examine fields; inspected information stays on your computer and is not recorded or sent by the extension.
